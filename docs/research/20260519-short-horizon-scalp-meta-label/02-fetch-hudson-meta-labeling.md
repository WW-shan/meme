# Source Note: Hudson & Thames Meta-Labeling

- Source: https://hudsonthames.org/does-meta-labeling-add-to-signal-efficacy-triple-barrier-method/
- Title: `Does Meta Labeling Add to Signal Efficacy?`
- Role in this experiment: methodological support for using a secondary model or gate on top of an existing primary signal.

## Relevant Takeaways

- Meta-labeling should filter or size opportunities generated by a primary signal, not replace the primary signal with a broad new entry source.
- It depends on contextual signal-time features and realistic out-of-sample validation.
- In this repo, that maps to preserving v95/v84 primary candidates and testing a narrow replay-only overlay instead of lowering the global threshold.

## Usage In This Cycle

This source supported the hypothesis that short-horizon rejected candidates should be treated as a secondary take/skip problem. The final replay rejected the simple rule overlay, so the next version should move toward a learned candidate-level meta-label or conditional-exit model.
